# concern-board｜關注點共編投票工具

為工作坊設計的即時共編與投票網頁：各組輸入關注點、合併相似題目、用手機分段投票，投影畫面即時顯示。

- 規格：[docs/spec.md](docs/spec.md)（Part A 是使用說明）
- 版本紀錄：[docs/release-notes.md](docs/release-notes.md)
- 正式網站：`https://mikelai70.github.io/concern-board/`

## 在自己的電腦上練習（本機預覽）

本機預覽會在你的電腦上開一個**練習用的完整環境**，不會碰到正式資料：

| 內容 | 說明 |
|---|---|
| 模擬的 Firebase | 資料庫和登入都是假的，只存在你的電腦記憶體裡 |
| 示範場次 `TEST26` | 已經是「進行中」、收集階段，有 2 題示範題目 |
| 本機網站 | `http://localhost:8000/` |

關掉之後資料就全部消失；下次再開，又是全新的示範場次。

### 第一次使用前（只需要做一次）
電腦要有 Node.js 和 Java（2026/11/20 已安裝）。在 concern-board 資料夾開 PowerShell，執行：
```powershell
npm install
```

### 開始練習
1. 在 concern-board 資料夾開 PowerShell，執行：
   ```powershell
   npm run dev
   ```
2. 等到畫面出現「按 Ctrl+C 結束。」（第一次約 30 秒）。**這個視窗不要關**，關掉網站就停了。
3. 用 Chrome 打開 `http://localhost:8000/`。畫面上方會有黃色提示「本機預覽模式」，代表現在用的是練習資料。

### 練習時可以用的帳號與密碼
| 角色 | 怎麼進入 |
|---|---|
| 參與者 | 場次代碼 `TEST26` → 輸入姓名、選組別 |
| 小幫手 | 場次代碼 `TEST26` → 展開「小幫手」→ PIN `111111` → 選組別 |
| 主持人 | 場次代碼 `TEST26` → 展開「主持人」→ PIN `222222` |
| 擁有者 | `http://localhost:8000/#/admin` → 按「用 Google 登入」（會直接登入測試擁有者，不會跳出 Google 視窗） |
| 投影畫面 | `http://localhost:8000/#/s/TEST26/screen` |

這些 PIN 只在練習環境有效，正式場次的 PIN 由擁有者在管理頁另外設定。

### 建議檢查的畫面
1. **小幫手**：按「新增一題」→ 打字、選分類 → 等右下角顯示「已儲存」。
2. **投影畫面**：開另一個分頁看題目有沒有即時出現；右上角可以切換「依組別／依分類」。
3. **重新整理**：小幫手打到一半（還沒選分類）就重新整理頁面，打的字應該還在。
4. **擁有者**：建立場次、設定 PIN、切換可見性、匯出 JSON 再匯入。
5. **手機尺寸**：在 Chrome 按 F12 → 左上角的手機圖示，看小幫手和參與者畫面。
6. **複製到另一類**（收集階段）：在小幫手畫面按題目旁的「複製到另一類（並改寫描述）」，應該多出一題在另一類、勾著「已改寫」。合併後的題目不會出現這個按鈕（要先拆回）。
7. **切換階段**：以主持人進入 → 按「前往『協力統整』」。
8. **合併**（合併階段，小幫手畫面）：
   - 勾選不同分類的 2 題 → 下方提示「不同分類的題目不能合併」，按鈕不能按。
   - 把其中一題的分類改成一致 → 題目移到同一區 → 勾選 → 「合併」→ 改寫文字 → 「確定合併」。
   - 合併後的題目應顯示兩個組別、勾著「已改寫」、列出「合併自」。
   - 按「拆回」或「刪除」（選「拆回」），應恢復成原本的題目。

小提醒：主持人和小幫手可以用同一個瀏覽器分頁輪流扮演（先進主持人，再回到 `#/s/TEST26/helper`）。

### 注意事項
- **同一個瀏覽器的分頁共用同一個登入身分。** 在一個分頁登入擁有者後，其他分頁會回到選身分的畫面，這是正常的。想同時扮演多個角色，可以另開無痕視窗（Ctrl+Shift+N）。
- 想在本機連到**正式** Firebase（例如部署規則後檢查），網址加 `?prod`：`http://localhost:8000/?prod#/admin`。這時操作的是正式資料，請小心。

### 結束練習
回到執行 `npm run dev` 的 PowerShell 視窗，按 **Ctrl+C**。

### 常見問題
| 畫面訊息 | 原因與處理 |
|---|---|
| 「無法啟動：連接埠 … 已經被占用」 | 已經有一份在執行。直接打開 `http://localhost:8000/` 就能用；要重開，先到那個視窗按 Ctrl+C，再執行一次 `npm run dev` |
| 「emulator 意外結束」 | 通常是 Java 沒裝好。把畫面上的訊息貼給 Claude |
| 網頁打不開 | 確認 `npm run dev` 的視窗還開著，而且有出現「按 Ctrl+C 結束。」 |
